# Parashar Lighting Atelier

> Monumental Architectural Spatial Luminaires, Hand-Burnished Brass Patinas & Bespoke Lighting Installations for Landmark Architecture Worldwide.

## ✦ Overview
Parashar Lighting is a luxury architectural lighting brand and Jaipur-based atelier. This application is built with Next.js 15 App Router, React 19, TypeScript, and Tailwind CSS.

### Key Features:
- **Hospitality & Landmark Portfolio**: 17 premier landmark properties across India (Suryagarh, Fairmont Jaipur, Raffles Udaipur, Umaid Bhawan Palace, Villa Palladio, City Palace, etc.).
- **Atelier Monograph Dossiers**: Architectural specification sheets, CAD blueprints, and custom drop length schedules.
- **Interactive Luminaire Catalog**: Curated collections of chandeliers, wall sconces, pendants, and surface mounts.
- **Dynamic Trade Concierge**: Direct quotation and trade desk consultation routing.

## ✦ Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
